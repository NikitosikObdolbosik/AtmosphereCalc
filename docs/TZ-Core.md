# Техническое задание: Разработчик CORE (C#)

Твоя задача — поддерживать и развивать математическую модель расчёта физики атмосферы и логику представления (ViewModel) по архитектуре MVVM.

## Твои папки

| Папка | Что там |
|---|---|
| `src/AtmosphereCalc.Core/Models/` | Физика ISA (`AtmosphereCalculator`), результат расчёта, слои, экспорт CSV |
| `src/AtmosphereCalc.Core/ViewModels/` | `MainViewModel` и всё, что готовит данные для окна: форматирование, строки таблицы, деления осей |
| `src/AtmosphereCalc.Core/Services/` | Интерфейсы сервисов, которые ViewModel просит у окна (сохранение файла, снимок графика) |
| `tests/AtmosphereCalc.Core.Tests/` | Тесты модели и ViewModel |

Проект `AtmosphereCalc.Core` **не должен ссылаться на Avalonia**: всё, что связано с отрисовкой и диалогами, делает UI через интерфейсы из `Services/`.

## Граница с UI

Окно привязано к публичным свойствам и командам `MainViewModel`. Если переименовываешь или удаляешь такое свойство — согласуй с UI и попроси его ревью в PR. Новое свойство вливай раньше, чем UI начнёт к нему привязываться.

## Что нужно делать

1. Клонировать репозиторий и создать свою ветку от `main`:
   ```bash
   git checkout -b feature/core-<коротко-о-задаче>
   ```
2. Любое изменение модели — вместе с тестом в `tests/AtmosphereCalc.Core.Tests/`.
3. Перед PR проверить локально:
   ```bash
   dotnet test AtmosphereCalc.slnx
   ```
4. Открыть PR в `main` с описанием «Что сделано / Как проверено / Что не сделано» и попросить ревью у UI или тимлида.
